## 📖 Overview

This repository contains documentation for various software projects and development guides, built with VitePress for a modern, searchable documentation experience.

## 📁 Documentation Structure

- **Project Documentation**: Detailed guides for individual projects
- **Developer Docs**: Technical documentation and API references
- **Architecture**: System design and implementation details
- **Guides**: Tutorials and how-to articles

## 🚀 Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Local Development
```bash
cd docs
npm install
npm run dev
```

### Building
```bash
cd docs
npm run build
```
